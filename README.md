# ⎈ Kubernetes Study Vault

A free, self-contained Kubernetes learning hub: an interactive cluster architecture, topic deep dives, interview Q&A, labs and a kubectl reference.

**Live site:** https://deven1003.github.io/study-vault-kubernetes/

## What's inside

- **Interactive architecture:** click any control-plane or node component for full details
- **Topic-wise deep dives**
- **30+ interview Q&A**
- **Hands-on practice labs**
- **Practical Kubernetes use cases**
- **kubectl quick reference**

## Run locally

Everything is in a single `index.html`, so there's no build step:

```sh
git clone https://github.com/deven1003/study-vault-kubernetes.git
cd study-vault-kubernetes
# open index.html in your browser
```
